# Recipe Flowchart

Single-page app that renders recipes as flowcharts (Plate, Ribbon, and Bracket views).
Everything — styles, script, and recipe data — lives in `index.html`.

## Run

```
npm run dev
```

Serves `index.html` at every path. Requires Node 18+; no dependencies.
`PORT` (default 3000) and `HOST` (default 127.0.0.1) set the listen address.
